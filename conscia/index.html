Conscia

Connect to a “real node out there” endpoint (for example: your laptop’s Conscia node tunneled via zrok).

Identity (did:peer)

This page can attach your did:peer identifier to requests so Conscia can attribute activity. (Your secret should stay on your device; we do not send it.)

Nodes

Save multiple Conscia node endpoints (for example: https://consciawarsaw.share.zrok.io, https://conscialivorno.share.zrok.io) and observe them together.
